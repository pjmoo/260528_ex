01

DOM 조회 (DOM Reading)

HTML 요소를 JavaScript로 가져오는 명령어입니다. 가장 대표적인 도구는 querySelector와 querySelectorAll입니다.

📌 선택자 꿀팁!
- 태그 이름만 적기: "p"
- 고유 ID 가져오기: "#healer" (앞에 샵(#)을 붙임)
- 공통 클래스 가져오기: ".job" (앞에 점(.)을 붙임) 
// 1. 최초 1개의 요소만 검색
const healer = document.querySelector("#healer");

// 2. 클래스가 job인 모든 요소를 찾아 배열형태로 반환
const jobs = document.querySelectorAll(".job");
console.log(...jobs); // 전개연산자로 펼쳐보기
실시간 체험존: DOM 조회

⚔️ 전사 (class="job")

<p class="job">

🔮 마법사 (class="job")

<p class="job">

💖 힐러 (class="job", id="healer")

<p class="job" id="healer">

🎒 모험가 (일반 태그)

<p>
> 대상을 클릭하여 검색 결과를 터미널 로그로 확인해 보세요.
02

DOM 조작 (DOM Managing)

새로운 HTML 요소를 동적으로 만들고, 스타일과 클래스를 변경하며, 화면에 붙이고 떼어내는 기술입니다.

⚠️ 보안 수칙! innerHTML vs textContent
innerHTML은 사용자의 입력을 날것 그대로 렌더링하므로 해킹(XSS 공격)에 매우 취약합니다. 단순 글씨를 넣을 때는 안전하고 속도가 빠른 textContent를 사용하세요. 
// 1. 요소 생성
const box = document.createElement("p");
box.textContent = "안전한 텍스트";

// 2. 클래스 추가 및 토글
box.classList.add("switch", "border");
box.addEventListener("click", () => box.classList.toggle("switch"));

// 3. style 조작 (CamelCase 적용 필수)
box.style.fontSize = "24px"; // font-size (X)

// 4. 화면 추가 및 제거
container.append(box);
box.remove(); // 스스로 삭제
실시간 체험존: DOM 생성/토글/삭제
기본 제공 박스 (클릭시 클래스 토글)
> 생성한 박스를 클릭하면 .classList.toggle('switch')가 실행되어 배경색이 변합니다. X 버튼을 클릭하면 .remove()가 작동합니다.
03

이벤트 리스너 (Event Listener)

웹사이트에서 클릭, 키보드 입력, 마우스 이동 등 특정 행동이 감지되었을 때 미리 정의한 코드가 예약 실행되게끔 설정하는 방법입니다.

⭐ addEventListener가 좋은 이유:
1. 하나의 버튼에 **여러 개의 서로 다른 동작**을 병렬로 등록할 수 있습니다.
2. 이벤트를 원할 때 지울 수도 있어 메모리 관리에 효율적입니다. 
// 1. 프로퍼티 방식 (덮어쓰기 위험이 있음)
btn.onclick = () => console.log("작동되지 않음");
btn.onclick = () => console.log("마지막 이벤트만 작동!");

// 2. 리스너 방식 (모든 리스너가 누적 실행됨)
btn.addEventListener("click", () => console.log("액션 1"));
btn.addEventListener("click", () => console.log("액션 2"));

// 3. 지울 때는 반드시 함수의 레퍼런스(이름)가 필요함
const runOnce = () => {
  console.log("한 번만 실행되고 지워짐!");
  btn.removeEventListener("click", runOnce);
};
btn.addEventListener("click", runOnce);
실시간 체험존: 이벤트 연결 & 지우기
> 버튼들을 눌러 실행 결과가 터미널 로그에 쌓이는 차이점을 관찰해 보세요.
04

이벤트 타입 & 진입점 (Event Types)

웹 브라우저의 대표적인 진입점 이벤트와 입력창의 상태 변화에 따른 이벤트 4인방을 알아봅니다.

📁 DOMContentLoaded:
HTML 구조가 브라우저에 전부 뿌려진 직후 발동되므로, 스크립트 파일이 HTML 코드보다 앞서 실행되어 발생하는 null pointer error를 원천 차단하는 진입점 역할을 합니다. 
// 1. DOM 진입점 설정
document.addEventListener("DOMContentLoaded", () => {
  console.log("HTML이 로드되었으므로 이제 안심하고 요소를 검색하세요!");
});

// 2. 대표 입력창 이벤트
input.addEventListener("input", (e) => console.log("타이핑 실시간 감지: ", e.target.value));
input.addEventListener("change", (e) => console.log("포커스가 풀려 입력 확정: ", e.target.value));
input.addEventListener("focus", () => console.log("입력창에 커서 켜짐"));
input.addEventListener("blur", () => console.log("입력창 탈출"));
실시간 체험존: 입력창 상태 실시간 감지
실시간 입력값: - 입력 글자수: 0자
> focus, blur, input, change 이벤트의 실시간 반응 로그가 기록됩니다.
05

다양한 Input과 값 가져오기 (Inputs)

웹에서 사용하는 입력 도구들의 특성과 JS에서 그 타입 및 체크 상태를 읽는 정밀 제어 방식입니다.

🚨 주의: input value의 근본적 특징
체크박스(checked 불리언 값)를 제외한 type="number", type="range" 등은 화면상 숫자처럼 보일지 몰라도 JavaScript로 읽어올 때는 항상 문자열(string) 타입으로 읽어집니다. 따라서 산술 계산 시 형변환이 필수입니다! 
// 1. 일반 텍스트 및 숫자 입력값 읽기
console.log(typeof numInput.value); // "string"

// 2. 체크박스는 value가 아닌 checked를 읽어와야 함
const isChecked = checkbox.checked; // true / false (Boolean)

// 3. 셀렉트 박스의 선택값
const petType = selectBox.value; // "강아지" 등
실시간 체험존: 폼 인풋 데이터 실시간 디버거
항목 속성명 수집값 (JS 리턴) 데이터 타입
위 버튼을 클릭하여 입력을 캡처해 분석하세요.
06

Form 제출 & 객체화 (Forms)

폼의 기본 전송 행동으로 페이지가 새로고침되는 것을 막고, 입력받은 대량의 정보를 FormData를 통해 매우 빠르고 세련되게 추출해 객체 형태로 가공하는 방식입니다.

📁 preventDefault() 와 FormData
- event.preventDefault(): 폼 제출 시 깜빡이면서 새로고침되는 브라우저의 기본 처리를 완전 차단합니다.
- new FormData(form): 폼 내의 name 속성을 기준으로 데이터를 자동 바인딩합니다.
- Object.fromEntries(formData): 데이터를 보기 쉬운 깔끔한 JS 객체(JSON 구조)로 원클릭 변환합니다. 
form.addEventListener("submit", (event) => {
  event.preventDefault(); // 기본 새로고침을 무효화
  
  // name 속성값을 가진 인풋들을 객체화
  const formData = new FormData(event.target);
  const data = Object.fromEntries(formData);
  
  console.log(data); // { username: "윌리엄", pokemon: "꼬북이" }
});
실시간 체험존: FormData 직렬화 테스트
시작 포켓몬 (name="pokemon")
추출 완료된 데이터 객체 (Object):
{ "status": "제출 버튼을 클릭하면 이곳에 변환된 JSON 객체가 표시됩니다." }
07

BOM (Browser Object Model)

웹 브라우저 창 그 자체와 관련된 크기, 타이머, 주소 경로, 스크롤 이동 등을 제어하기 위한 인터페이스입니다. 최상위의 window 객체가 이 모델을 대변합니다.

⏰ 타이머 2대 천왕
- setTimeout: 일정 시간 후에 특정 함수를 단 한 번만 실행합니다.
- setInterval: 일정 주기가 돌아올 때마다 함수를 영원히 반복 실행합니다. (중지는 clearInterval) 
// 1. 주기적인 상대적 스크롤 하강 타이머 작동
const scrollTimer = setInterval(() => {
  window.scrollBy(0, 50); // 아래 방향으로 50px 상대 이동
}, 1000);

// 2. 타이머 멈추기
clearInterval(scrollTimer);

// 3. 브라우저 크기 정보 얻기
console.log(window.innerWidth, window.innerHeight);
실시간 체험존: 브라우저 속성 및 타이머 제어

- px
innerHeight
- px
scrollY (스크롤)

글로벌 this 확인

반복 카운트: 0 중지됨
> 현재 화면 창 크기(innerWidth/Height) 및 스크롤 위치가 감지되었습니다.

웹 스토리지 & 클립보드 (Storage & Clipboard)

사용자의 데이터를 서버 데이터베이스 없이도 로컬 브라우저 환경에 쉽게 저장하거나 컴퓨터의 클립보드 기능과 호환해 쓸 수 있게 돕는 유용한 브라우저 API 모음입니다.

📦 스토리지는 오직 문자열(String)만 기억합니다!
객체(Object)나 배열(Array)을 그대로 집어넣으면 강제로 [object Object] 문자로 으깨어 저장되므로, 반드시 JSON.stringify()를 사용해 문자 형태로 직렬화하여 담아야 온전히 데이터를 저장할 수 있습니다. 
// 1. 객체를 문자열로 가공해 로컬스토리지에 저장
const user = { name: "홍길동" };
localStorage.setItem("user", JSON.stringify(user));

// 2. 문자열 형태로 가져와 다시 객체로 변환
const data = JSON.parse(localStorage.getItem("user"));
console.log(data.name); // "홍길동"

// 3. 클립보드에 텍스트 복사하기
navigator.clipboard.writeText("부자가 되는 법!");
실시간 체험존: 스토리지 비교 & 클립보드 복사
